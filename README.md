# thought-engine

Posts and visuals on AI infrastructure, agentic systems, and higher education.
Built with [Eleventy](https://www.11ty.dev/) and [Pagefind](https://pagefind.app/), deployed to GitHub Pages.

- `/`: all posts
- `/visuals/`: every post visual in a filterable gallery
- `/search/`: full-text search across posts, visual descriptions, and keywords

```bash
npm install
npm start   # http://localhost:8080/thought-engine/
```

Post format and front matter: see [CLAUDE.md](CLAUDE.md).
